# MN — списъци за разрешение и версии

Това хранилище държи няколко текстови файла, които плъгините MN четат сами през
интернет. Нищо тук не е тайно:

- `licence.txt` — кои компютри имат право и до кога. Подписан. Компютрите са
  номера (отпечатъци), не имена.
- `revoked.txt` — отнети веднага. Може да се пипне и от телефон.
- `plugins.txt` — коя версия на кой плъгин и откъде се сваля. Подписан.
- `files/` — телата на плъгините. Заключени са: без ключа не се четат.

Редактира се само през инструментите в проекта (подписите трябва да съвпадат).
